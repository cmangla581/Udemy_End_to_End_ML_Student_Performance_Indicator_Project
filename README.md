# Udemy_End_to_End_ML_Project
This is  basically an end to end machine learning project under the Udemy course of Krish Naik sir which are being done here for practice and the proper implementation of the machine learning algorithms.  

The project basically shows that how the student's performance (test scores) is affected by the other variables such as Gender, Ethnicity, Parent level of education,
Lunch and Test preparation course.  

This project is done for practice purpose and it include the proper implementation of the project including the machine learning algorithms like the Decision Tree Classifier, Random Forest Classifier and the Linear Regression. 

Here along with the notebooks implementation, the project also includes the proper model and  the pipeline training. At the end, I also tried to implement the project by using the Flask but still trying it. 
This was truly an interesting project to practice.  

Life cycle of Machine learning Project

- Understanding the Problem Statement
- Data Collection
- Data Checks to perform
- Exploratory data analysis
- Data Pre-Processing
- Model Training
- Choose best model
